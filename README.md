# بصيرة — Basira

تطبيق تعلّم عربي للكبار، مبني بـ Flutter، مع معاينة ويب مستقلة للتصميم والتفاعل.

## محتوى النسخة الأولى

- الكتب الثلاثة الأصلية محفوظة كما هي (87 + 10 + 13 = 110 صفحات).
- `assets/data/books.json`: النص المستخرج من جميع الصفحات مع أرقامها الأصلية؛ قد يتضمن أخطاء استخراج عربية وصفحات بلا نص.
- `assets/data/questions.json`: **30 سؤالًا تدريبيًا معاد الصياغة**، وليست نقلًا كاملًا لكل أسئلة الكتب. لكل سؤال كتاب وصفحة وإجابة ونوع وملاحظة منشأ.
- اختيار من متعدد، صح/خطأ، وإجابة قصيرة بتقييم ذاتي واضح (لا يوجد تصحيح دلالي آلي).
- مكتبة، بحث وتصفية، حفظ الأسئلة، تدريب، اختبارات، سجل نتائج ومراجعة الأخطاء.
- التخزين محلي؛ لا توجد حسابات أو مزامنة سحابية. تبقى البيانات الدينية منسوبة للمراجعات ولا تمثل فتوى مستقلة.

لم تُستكمل إجابات الأسئلة التي تركها المصدر فارغة. يلزم تدقيق بشري للمحتوى قبل إصدار تعليمي عام، والتحقق من حقوق إعادة نشر الكتب؛ وجودها في GitHub لا يمنح ترخيصًا تلقائيًا.

## تشغيل Flutter

يلزم Flutter حديث (3.24 أو أحدث) وDart 3.4 أو أحدث. ملفات المنصات تُولّد محليًا:

```bash
flutter create --platforms=android,ios,web --project-name basira .
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
# أو على جهاز Android متصل:
flutter run
```

التطبيق في `lib/main.dart` ويستخدم الملفات المشتركة في `assets/data/`. قد تضيف عملية `flutter create` اختبارًا افتراضيًا `test/widget_test.dart`؛ احذفه إذا كان يختبر تطبيق العداد الافتراضي بدل بصيرة. لتوليد iOS وبنائه تحتاج macOS وXcode.

**حالة التحقق:** تعذّر تنزيل Dart SDK بسبب حجب الاتصال بخوادم Flutter في بيئة العمل، لذلك لم يتم تشغيل أو بناء أو تحليل كود Flutter. لا تتوفر نسخة APK مختبرة بعد.

## المعاينة التفاعلية

هذه معاينة HTML/CSS/JavaScript مستقلة، **وليست Flutter Web مترجمًا**. تستخدم نفس بنك المحتوى وتخزن النتائج في المتصفح، بصورة منفصلة عن تطبيق Flutter.

```bash
python3 tools/preview_server.py
# http://localhost:3000
```

الخادم مخصص للتطوير المحلي فقط، وليس للنشر الإنتاجي.

## إعادة استخراج النص

```bash
python3 -m venv .venv
.venv/bin/pip install pymupdf
.venv/bin/python tools/extract_books.py
python3 tools/validate_content.py
```

إعادة الاستخراج لا تولّد الأسئلة تلقائيًا. الأسئلة التدريبية أُعدت من النصوص المقروءة وربطت يدويًا بصفحات PDF (عدّ الصفحات يبدأ من 1).

## الخطوات التالية

مراجعة بقية محتوى الكتب تدريجيًا، إضافة أنماط المطابقة والترتيب والاختيار المتعدد الإجابات، ثم اختبار التطبيق على الأجهزة وإعداد إصدار للنشر. هذه الأنماط ليست ضمن النسخة الحالية.

## تحقق المعاينة

```bash
npm install
npm test
node --check preview/app.js
```

اجتاز اختبار DOM: التنقل والبحث، التدريب، التقييم الذاتي، إكمال الاختبار، حفظ الأسئلة والنتائج محليًا، عرض المصدر، وسجل التقدّم. اجتاز بنك المحتوى فحص البنية والمراجع. تم فحص نحو Dart بمحلل مستقل دون أخطاء؛ هذا لا يغني عن `flutter analyze` أو اختبار الأجهزة. لم يكتمل اختبار متصفح Chromium لغياب مكتبات النظام وتعذّر تنزيلها.
