# بصيرة — تعلّم يثبت

تجربة تعلّم عربية مباشرة: **لا مكتبة ولا فتح كتب داخل واجهة المتعلّم**. كود Flutter ومعاينة ويب مستقلة، وكلاهما يستخدم بنكًا مشتقًا من `sorular.txt` وحده.

## ما أنجز

- **7,518 صيغة تدريب قابلة للحل** + سجل توثيقي واحد خارج التدريب والتقييم.
- **24 نوعًا** من الأنشطة: الاختيار الأحادي والمتعدد، صح/خطأ، الإكمال، الكتابة، الاستنتاج، التلميحات، التعليل، المقارنة، الترتيب، المطابقة، القراءة ومجموعات الأسئلة.
- 504 وحدات نصية في أجوبة الملف: **502 وحدة لها تمارين**، ووحدتان من المقطع 176 محفوظتان للتوثيق النقدي ولا تتحولان إلى تدريب على إيذاء الأشخاص.
- يحتفظ البنك بـ189 مجموعة السؤال/الجواب الأصلية كاملة، و65 نشاطًا مفصلًا أُعد سابقًا، ثم **7,265 نشاطًا استخراجيًا إضافيًا**. المجموع 7,519 سجلًا.
- كل صيغة مرتبطة بمقطعها، وأسطر المصدر، ودليل نصي، ومفهوم/وحدة معرفية. `assets/data/coverage.json` سجل تغطية قابل للتحقق.

**هذه آلاف صيغ التدريب على المحتوى نفسه، وليست آلاف معلومات أو أحكام مستقلة.** معظم التوسعة استخراج وإكمال وتذكّر نصّي، بتغيير مواضع الفراغات وأسلوب السؤال. الأنواع التفسيرية تعرض المرجع وتطلب تقييمًا ذاتيًا. لا ندّعي توليد أسئلة بتدقيق بشري مستقل أو تصحيح دلالي بالذكاء الاصطناعي.

## رحلة المتعلّم

- صفحة بداية، ثلاثة مسارات، بنك تدريبات ببحث وتصفية وصفحات، اختبارات، «فرصتي الثانية»، تقدّم ومحفوظات.
- الخيارات تخلط عند كل عرض جديد للسؤال، ويتغير **موضع الإجابة الصحيحة** عن العرض السابق للاختيار الأحادي. مجموعة المواضع الصحيحة للاختيار المتعدد تتغير أيضًا.
- الخلط لا يتكرر أثناء الكتابة أو الحفظ أو كشف التلميح، حتى لا تقفز الإجابة المختارة. صحة الإجابات مرتبطة بالقيم، لا بأرقام المواقع.
- ترتيب الخيارات والمطابقات وأجزاء مجموعة الأسئلة يتغير دون المساس بالمراجع الصحيحة.
- كل إجابة مثبتة تسجل فورًا، حتى إن خرج المستخدم قبل نهاية الجلسة. الإجابات غير المثبتة محفوظة كمسودة فقط.
- **كل الأخطاء المعلّقة تدخل الاختبار القادم تلقائيًا**، حتى لو كانت من مسار آخر، أو كانت إجابة مفتوحة، أو تجاوز عددها عدد الاختبار المختار. الواجهة توضح ذلك قبل البدء.
- يحتاج الخطأ إلى إجابتين صحيحتين في **جلستين مختلفتين** للخروج من قائمة المراجعة. الخطأ مجددًا يعيده إليها.
- تُفضّل مفاهيم مختلفة في الجلسة نفسها بدل تكرار عدة صيغ للفكرة ذاتها، مع بقاء جميع الأخطاء المطلوبة في الاختبار.
- في الاختبار تؤجل الإجابات المفتوحة إلى شاشة تقييم ذاتي بعد الحل؛ لا تعتبر خطأً تلقائيًا. لا تُعتمد النتيجة النهائية قبل إكمال هذا التقييم.
- حفظ واستئناف الجلسة، هدف يومي، مؤشرات تقدم حقيقية، إنجازات في المعاينة، تكبير الخط، وضع التركيز، وتقليل الحركة. يدعم الويب تفضيل النظام `prefers-reduced-motion`.
- البيانات محلية على الجهاز/المتصفح؛ لا حسابات ولا مزامنة سحابية. الترحيل من سجل نسخة sorular السابقة يحافظ على الأسئلة المحفوظة ويستخرج أخطاء المحاولات السابقة.

## مصدر المحتوى وحدوده

الملف الأصلي محفوظ بايتًا ببايت: 121,988 بايت، 1,414 سطرًا، 189 مجموعة مكتملة و34 قالبًا فارغًا. لم تُخترع إجابات للفراغات. لم تُستخدم ملفات PDF القديمة لتوسعة البنك ولم تُحذف ملفات المستخدم الأصلية.

المراجعة الأصلية المثبتة في GitHub: `5a33de834bf9a9fc7b16ef90c56d4bf63a97270b`.

SHA-256: `7673d1306e1b1ecdd0f929d559b0d5d4b790e534f34274622260356c91df5452`.

الملف يتضمن أخطاء نسخ ونقولًا وآراء فقهية مختلفة. لم تُصحح بصمت. التقييم يعني **موافقة مرجع المراجعة**، لا صحة الفتوى أو توثيق الآية/الحديث. يلزم تدقيق مختص قبل النشر التعليمي العام والتحقق من حقوق المحتوى.

المقطع 176 الذي يتضمن استباحة دم ومال المخالف محفوظ توثيقيًا مع تحذير في بيانات المصدر، لكنه لا يظهر كتدريب أو يدخل أي اختبار. الحفاظ على المصدر ليس إقرارًا بمحتواه.

[تقرير التغطية](docs/sorular-coverage.md) — للتدقيق في المستودع، وليس زرًا لفتح كتاب داخل التطبيق.

## التشغيل

### معاينة الويب

```bash
python3 tools/preview_server.py
# http://localhost:3000
```

معاينة HTML/CSS/JavaScript مستقلة، **وليست Flutter Web مترجمًا**. الخطوط مرفقة محليًا. يضغط الخادم بنك الأسئلة بـgzip، ويعرض ملفات الواجهة والبيانات المطلوبة فقط؛ ملفات `.git` والمصدر الخام ليست متاحة عبره. خادم تطوير، لا خادم إنتاج.

### Flutter

يلزم Flutter حديث وDart 3.4 أو أحدث:

```bash
flutter create --platforms=android,ios,web --project-name basira .
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```

ملفات المنصات تولد محليًا. احذف اختبار العداد الافتراضي `test/widget_test.dart` إن أضافه `flutter create`. يتطلب iOS نظام macOS وXcode.

**لم يتم بناء Flutter أو تشغيل `flutter analyze/test`: SDK غير موجود، وفشل الاتصال بخادم تنزيله.** فحص الصياغة بمحلل Dart ليس بديلًا عن التحليل والبناء. لا توجد APK مختبرة.

تطبق نسخة Flutter قواعد الخلط وإعادة الأخطاء وحفظ الجلسة والتقييم الذاتي والإعدادات نفسها، لكن لا يُدّعى تطابق كل تفاصيل الرسم أو التكافؤ المثبت على جهاز حقيقي.

## بناء البنك والتحقق

```bash
python3 tools/expand_learning.py
# أو python3 tools/import_sorular.py (يبني التوسعة كاملة أيضًا)
python3 tools/validate_content.py
python3 -m unittest discover -s test -p '*_test.py'
npm ci
npm test
```

- الاستيراد يحتفظ بكل حرف من الملف وبكل سؤال وجواب أصلي.
- التوسعة حتمية، وتحتفظ بمرجع الوحدة وبالسياق والجواب لكل صيغة.
- الفاحص يتحقق من التغطية لكل وحدة، وأنواع الأسئلة والإجابات والمراجع ومعرّفاتها.
- الاختبارات تغطي تصحيح البنك كاملًا، الأنواع الـ24، الترحيل/الحفظ، المسودات، الخلط، سلامة الإجابة بعد تغيير الموضع، إدراج أخطاء الأسئلة المفتوحة في الاختبار التالي، التقييم الذاتي المؤجل، وإتقان السؤال ثم عودة الخطأ.
- لتحديث الملف: راجع المحتوى الجديد وحدّث `COMMIT` و`EXPECTED_SHA256` معًا في `tools/import_sorular.py`. لا تنسب نسخة جديدة إلى مراجعة قديمة.

### تحقق المتصفح المنفذ

تمت تجربة Chromium فعليًا: تحميل الخط العربي المحلي، أحجام 320/390/768/1440 بكسل دون تجاوز أفقي، احترام تقليل الحركة، حفظ الأخطاء عبر إعادة التحميل وإعادتها للاختبار التالي، تغير مواضع الإجابات، الاستئناف من المسودة، وعناصر المطابقة والترتيب والمجموعات على الهاتف. لم تظهر أخطاء JavaScript أثناء هذه السيناريوهات. تفاصيل ذلك في `docs/testing.md`.

## ملفات مهمة

- `preview/learning.js` و`lib/learning_engine.dart`: اختيار الجلسة، ذاكرة الأخطاء، الخلط.
- `preview/app.js` و`lib/main.dart`: واجهات التعلّم وحفظ الحالة والتقييم الذاتي.
- `assets/data/questions.json`: البنك الحالي؛ `coverage.json`: التغطية؛ `types.json`: تعريف الأنواع.
- `tools/expand_learning.py`: التوسعة؛ `tools/import_sorular.py`: استيراد المصدر والتوثيق.

## الخطوط

الخط العربي مشتق من IBM Plex Sans Arabic، وخطوط الرموز من Noto، وفق التراخيص المرفقة في `assets/fonts/*LICENSE.txt`. ملفات Flutter باسم **Basira Arabic** تدمج المجموعتين العربية واللاتينية من الخط وتغير الاسم للنسخة المشتقة. خطوط الويب المحلية تحافظ على مجموعات المصدر كما هي.

لإعادة اختبار المتصفح مع تشغيل خادم المعاينة، استخدم `test/browser_smoke.cjs` بعد تثبيت Playwright ومتصفحه محليًا. يدعم `BASIRA_PREVIEW_URL` لتحديد عنوان المعاينة، و`BASIRA_LAMBDA_CHROMIUM=1` لاستخدام حزمة Chromium المخصصة لبيئة العمل عند توفرها. هذا الاختبار اختياري وليس جزءًا من `npm test` خفيف الاعتمادات.
