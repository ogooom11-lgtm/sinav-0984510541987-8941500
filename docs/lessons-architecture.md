# الدروس والتطبيق الفوري

## نطاق المحتوى

11 درسًا منتقى، 42 عنصرًا تعليميًا و84 صيغة اختيار (ربط العنوان بالعبارة والعكس). هذه ليست 84 حقيقة مستقلة ولا تغطية كاملة للمصادر. التقسيم:

- sorular: ثلاثة دروس / 24 سؤالًا.
- الملف 2: خمسة دروس / 38 سؤالًا.
- الملف 3: ثلاثة دروس / 22 سؤالًا.

جميع العبارات التعليمية مقتطفات موجودة حرفيًا في أجوبة المصادر. خطة التحرير `content/lesson_plan.py` تختار المفاهيم صراحة؛ لا استخراج عشوائي لكل سطر. كل فقرة تحمل الملف والمقطع والأسطر وبصمة المصدر. جميع البدائل أوصاف أو عناوين صحيحة في الدرس نفسه، لكن المطلوب ربط واحد بعينه. لا تبديل لكلمات الآيات والأحاديث. لا ادعاء بتحكيم فقهي مستقل. مقتطف الوضوء من المقطع 37 أصل محجور استُخدم بتحرير مستقل ومحدود لبيان الحركة فقط، لا بإعادة تفعيل السؤال القديم.

## الهيكل

- `lib/main.dart`: نقطة التشغيل وتصدير الرموز المتوافقة مع الاختبارات السابقة.
- `lib/app/app.dart`, `theme.dart`: التطبيق والتوجيه والثيم.
- `lib/features/lessons/domain/lesson.dart`: نماذج الدروس والفقرات والأسئلة.
- `lib/features/lessons/domain/lesson_store.dart`: عقد مستقل للتخزين، يفصل منطق التدريب عن SharedPreferences.
- `lib/features/lessons/domain/lesson_controller.dart`: التخطيط والتصحيح الفوري والتثبيت والاستئناف؛ لا يبني Widgets.
- `lib/features/lessons/data/lesson_repository.dart`: تحميل أصول التطبيق وحفظ JSON محليًا؛ قابلة للاستبدال في الاختبارات.
- `lib/features/lessons/presentation/`: شاشة الرحلة، بطاقات الفقرات، وخيارات الإجابة.
- `lib/features/legacy/learning_home.dart`: الواجهة السابقة معزولة، لا إعادة كتابة عمياء تلغي التقدم السابق. ما زالت شاشة تاريخية كبيرة ويمكن تفكيكها لاحقًا.
- `preview/lessons/`: معاينة ويب مستقلة للرحلة الجديدة؛ ليست بناء Flutter Web.
- `tools/build_lessons.py`: بناء حتمي، يعمل أيضًا بعد إعادة بناء المقررات.

## المنطق

- الشاشة الأساسية تعرض الدروس حسب الملف. مشاهدة الدرس أو تحديد «قرأت» لا يساوي الإتقان.
- التدريب الجديد كله اختيار إجابة واحدة من ثلاثة أو أربعة بدائل.
- اختيار البديل يصحح فورًا ويحفظ النتيجة، ويمنع تغييرها أو احتسابها مرتين. لا ينتقل تلقائيًا قبل قراءة التوضيح.
- الجلسات معزولة حسب الملف، بسقف 50 دون حشو أو تكرار. لذلك الاختبار الجديد لكل قسم أقل من 50 حاليًا، ويعرض العدد الفعلي.
- الأخطاء أولًا؛ مراجعة الأخطاء لا تضيف أسئلة غير مستحقة. إغلاق الخطأ يحتاج إجابتين صحيحتين في جلستين مختلفتين.
- ترتيب الخيارات محفوظ أثناء السؤال، وموضع الجواب يتغير عند إعادة السؤال. يحفظ التقدم وموضع الجلسة والخيار المثبت محليًا.
- حفظ Flutter متسلسل بلقطات مستقلة لمنع كتابة حالة أقدم بعد الأحدث. فشل التخزين يظهر للمستخدم مع إعادة محاولة.
- مفتاح جديد `basira-lessons-v1` لا يمحو أو يعيد احتساب تقدم `basira-learning-v2` القديم.
- الاختبارات القديمة: الأسئلة الآلية تكشف النتيجة فور التحقق أيضًا؛ الأجوبة المفتوحة تبقى تقييمًا ذاتيًا ولا يدّعي التطبيق تصحيحها تلقائيًا.

## التحقق وحدوده

`npm test` يشمل اختبارات المحرك والواجهة الجديدة مع القديمة. اختبارات Python تتحقق من أصل كل مقتطف وكل بديل وبصمات المصادر وثبات إعادة التوليد. أضيف اختبار Flutter للمتحكم والحفظ والاستئناف، لكن لم ينفذ لعدم توفر Flutter SDK. فحص تركيب Dart ليس بديلًا عن `flutter analyze` و`flutter test`.

فحص Chromium الحقيقي للمسار الجديد نجح على عروض 320 و390 و768 و1440: لا تجاوز أفقي، تصحيح فوري وقفل البدائل واستعادة الجلسة بعد إعادة تحميل الصفحة دون أخطاء JavaScript.
