# التحقق من نسخة الأقسام 2 و3

## تحقق منفّذ

تحديث التصميم: تنقّل علوي وبطاقات أقسام جديدة في Flutter والويب؛ إزالة الأنواع الأربعة من الكتالوج والبنك، وإخراج الإكمال الأصلي من التدريب. فحص استئناف الجلسات القديمة لمنع إعادة نشاط ملغى، مع الإبقاء على سجل المحاولات.

- `npm test`: تصحيح البنك كاملًا، الأنماط النشطة، عزل المصدر والصياغة، 50 سؤالًا، أولوية الأخطاء وحدّ عددها، بقاء الفائض، التبديل المستقر للخيارات، المسودات، التقييم الذاتي، الترحيل.
- `python3 -m unittest discover -s test -p '*_test.py'`: 9 اختبارات؛ نقل المصادر حرفيًا، الملف 2 ليس أسئلة أصلية، 61 سؤالًا في الملف 3، الاستبعاد النقدي، مراجع المعدّل من المصدر نفسه، حذف الإكمال، إعادة بناء حتمية.
- `python3 tools/validate_content.py`: المراجع، بايتات الملفات، جميع بطاقات الأصل، أدلة المعدّل، سجل وحدات sorular، الأنواع ومعرّفات الأنشطة المتقاعدة.
- `test/browser_smoke.cjs`: Chromium حقيقي، الخطوط المحلية، 320/390/768/1440 بكسل لكل الصفحات الست والإعدادات، الحركة المخفضة، الحفظ وإعادة التحميل، إعادة الخطأ في نفس الاختيار، تغيّر موضع الصحيح، الاستئناف، واجهات التفاعل، اختبار أصلي من الملف 3 بعدد 50، وعدم أخطاء JavaScript.
- تحليل نحوي لجميع ملفات Dart بواسطة tree-sitter. **ليس بديلًا عن Flutter SDK**؛ لم يُنفذ تحليل الأنواع أو اختبارات Flutter أو البناء.

## إعادة التشغيل

```bash
npm ci
npm test
python3 -m unittest discover -s test -p '*_test.py'
python3 tools/validate_content.py
python3 tools/preview_server.py
```

اختبار المتصفح اختياري ويحتاج Playwright وChromium:

```bash
npm install --no-save playwright
npx playwright install chromium
node test/browser_smoke.cjs
```

في بيئة Arena استُخدمت حزمة `@sparticuz/chromium` مع `BASIRA_LAMBDA_CHROMIUM=1`؛ هذه حزمة اختبار خارج التطبيق وليست اعتماد تشغيل له.

## حدود التحقق

- مطابق المصدر لا يعني توثيق صحة الأحكام أو النقول؛ لم يُجر تدقيق فقهي مستقل.
- الأسئلة التفسيرية لا تُصحح دلاليًا آليًا؛ المتعلم يقارن بالمرجع ويقيّم نفسه.
- مصدر الملف 2 يضم شرحًا، لذلك المطابق 38 بطاقة تذكّر، وليس 38 سؤالًا وجدناها في الملف.
- الملفات الخام وسجل التدقيق غير معروضة كقارئ كتاب داخل التطبيق.

## اختبارات مراجعة المنطق

أضيف `test/audit_engine_test.cjs` و`test/audit_preview_test.cjs` إلى `npm test`: استئناف جميع الأنماط، تسجيل الإجابة فور التحقق مرة واحدة، حدود المراجعة وفلاترها، استعادة المصدر، العدد الفعلي للاختبار، مقام مؤشرات التقدم، البيانات المحفوظة التالفة جزئيًا وفشل الكتابة. اختبارات Dart المقابلة مضافة لكن غير منفّذة لعدم وجود SDK. تفاصيل النطاق والنتائج في [تقرير التدقيق](logic-audit.md).
